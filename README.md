
# Inventory Management System

**Tech Stack:**
- React JS in Frontend
- React Router
- React-Redux
- Redux-Logger
- Reduxjs/toolkit
- React Icons
- axios
- react-hot-toast
- recharts for dashboard
- socket.io-client for notifications
- tailwindcss for designing
- Node JS in Backend
- Express JS in Backend
- Express Router for backend routes
- Cross-origin resource sharing (CORS)
- bcrypt for password encryption
- JsonWebToken Authentication
- multer for photo handling
- mysql2 for database management
- nodemon
- socket.io
- uuid for unique id
- MYSQL for service and Database
